# 改良項 類別 預期效益

⑦消息動態 Bento（主+次）+ 視覺占位佈局引導用戶讀最重要那條
⑧對比浮動 Dock（深色、置底）組件useCompare hook 終於落地

⑩跑馬燈 / 心形動畫 / 骨架屏微互動「網站活著」感

  3. P2（兩日）： 精選名校 Bento、消息動態 Bento、詳情頁 sticky tab + 底 CTA。
  4. P3： 跑馬燈、心形動畫、骨架屏微互動。
