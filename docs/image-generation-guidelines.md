# Image Generation Guidelines

Use this fixed spec for all `gpt-image-2` image generation in HKSchoolPlace.

## Core rule

Images must match the actual content. If the title is about swimming, dance, music, art, sports, tai chi, table tennis, or family activity, the subject in the image must clearly reflect that topic.

## Style spec

- Use a realistic editorial photo style.
- No people, no faces, no hands.
- No text, no logos, no signage, no watermark.
- Natural soft daylight.
- Slightly warm, slightly desaturated.
- Calm, clean composition.
- Horizontal 3:2 framing.
- Leave some open space for overlays.
- Keep one image style across the whole set.
- Avoid cartoon, illustration, 3D render, glossy fake perfection.

## Subject mapping

- Swimming: empty pool, lane ropes, water, deck.
- Dance: empty dance studio, mirrors, barre, wooden floor.
- Music: piano, practice room, instrument setup.
- Art: paint table, brushes, paper, studio desk.
- Sports: gym, court, track, training space.
- Tai chi: open sports area, calm outdoor exercise space, no people.
- Table tennis: indoor court or training room, paddles, table, net.
- Family: playroom, wooden toys, reading corner, activity corner.
- Other: choose the closest real scene that matches the title.

## Generation rule

If one image does not match the content closely enough, regenerate it until it does.
Do not keep a good-looking but wrong image.
