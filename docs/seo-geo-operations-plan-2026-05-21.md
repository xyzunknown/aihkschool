# HKSchoolPlace SEO / GEO 运营规划

更新日期：2026-05-21

## 完成标准

- 搜索引擎能抓取公开页面：主页、幼稚园列表、学校详情、SmartPLAY、活动、资讯、时间线和 App 页。
- AI 搜索能理解页面主题、引用标准链接，并避开账号、后台和 API。
- iOS 端有公开 App 落地页、App Store 文案素材、通用链接基础配置和系统搜索曝光。
- 站点有稳定标题、描述、分享图、站点地图、爬虫规则和结构化资料。
- 修改后能通过构建和页面检查。

## 定位

HKSchoolPlace 的核心搜索心智是：

- 香港幼稚园搜寻
- K1 / N 班 / K2 / K3 学额空缺
- 幼稚园学费、班制、语言、地理位置比较
- SmartPLAY 幼儿课程开报提醒
- 香港亲子活动与幼稚园阶段兴趣探索

## SEO 策略

1. 关键词布局
   - 首页：香港幼稚园、幼稚园搜寻、学额空缺、SmartPLAY、亲子活动。
   - 列表页：香港幼稚园搜寻、N 班、K1-K3、地区、学费、班别。
   - 学校详情页：学校名称 + 地区 + 幼稚园资料 + 学额 + 学费 + 申请资讯。
   - SmartPLAY 页：SmartPLAY 开报、幼儿课程、游泳、律动、美术、报名时间。
   - 活动页：香港亲子活动、幼儿活动、展览、体验、地区、免费活动。
   - 资讯页：香港教育资讯、幼稚园开放日、升学政策、面试。

2. 页面结构
   - 每个主要页面要有唯一标题和描述。
   - 每个可分享页面要有标准链接。
   - 详情页要清楚展示名称、地区、日期、费用、来源和下一步行动。

3. 抓取与索引
   - 公开页面允许主流搜索引擎和 AI 搜索抓取。
   - 账号、后台和 API 不进入索引。
   - sitemap 包含主要公开页面和可用详情页。

4. 内容运营
   - 每周更新：热门地区幼稚园、K1 空缺、SmartPLAY 开报、免费亲子活动。
   - 每月专题：N 班申请、国际幼稚园、九龙城/元朗/大埔等地区整理。
   - 每个专题要链接到相关学校、活动和课程。

## GEO 策略

1. 让 AI 容易引用
   - 提供 `llms.txt`，说明核心页面、引用方式和抓取边界。
   - 给学校、课程、活动和文章页面加入清晰的机器可读资料。
   - 避免阻挡 AI 搜索类爬虫访问公开页面。

2. 提高答案可信度
   - 学校页保留官方链接、更新时间、学额、学费和申请信息。
   - 活动和课程页保留主办方、地点、日期、费用和原始报名链接。
   - 资讯页保留来源链接。

3. 内容格式
   - 页面标题直接说明“是什么”。
   - 摘要覆盖家长最常问的问题：位置、学额、费用、时间、适合年龄、下一步。
   - 专题页用问答、清单和地区整理方式发布，方便 AI 摘取。

## iOS 运营策略

1. App Store
   - App 名称：HKSchoolPlace。
   - 副标题：香港幼稚园搜寻与学额提醒。
   - 关键词：香港幼稚园、K1、N班、学额、SmartPLAY、亲子活动、幼稚园比较、升学、国际幼稚园。
   - 截图重点：搜索、学校详情、SmartPLAY、活动、收藏提醒。

2. 网页到 App
   - 新增 `/ios-app` 作为 App 公开落地页，并让 `/app` 自动转到该页面。
   - 准备 Apple 通用链接文件；默认使用当前本机签名团队，正式发布时可用 `APPLE_TEAM_ID` 覆盖。
   - iOS 项目加入 Associated Domains 配置。

3. iOS 系统搜索
   - 将示例学校内容写入 Spotlight 索引。
   - 搜索词覆盖学校名、英文名、地区、学额、N 班、K1 和 SmartPLAY。
